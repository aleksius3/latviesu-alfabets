LATVIEŠU ALFABĒTS — PWA

Запуск локально:
1. Не открывай index.html двойным кликом: service worker так не работает.
2. Запусти папку через любой HTTPS/HTTP сервер.
   Например на компьютере:
      python3 -m http.server 8080
   Затем открой http://IP_КОМПЬЮТЕРА:8080 на iPhone в Safari
   (iPhone и компьютер должны быть в одной Wi‑Fi сети).

Установка на iPhone:
Safari → Поделиться → На экран «Домой».

Управление:
- тап по карточке: следующая буква
- свайп влево: следующая
- свайп вправо: предыдущая
- кнопка ‹: предыдущая
- 🔊: произнести букву и слово через системный голос iOS

Важно:
Для настоящей установки PWA вне локальной сети сайт лучше разместить по HTTPS
(например GitHub Pages / Netlify / Cloudflare Pages).
