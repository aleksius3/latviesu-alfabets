LATVIEŠU ALFABĒTS V5

Новые режимы:
1) MĀCIES — полноэкранные карточки, свайп, быстрый нижний скролл, MP3.
2) SPĒLĒ:
   - Atrodi attēlu — найти правильную картинку.
   - Atrodi burtu — найти правильную букву.
   - Atrodi pāri — memory 3 пары.

Интерактив:
- звёзды за правильные ответы;
- серия правильных ответов;
- каждые 5 правильных подряд — Malacis! + конфетти + звуковой джингл;
- после каждых 5 изученных букв появляется предложение сыграть;
- прогресс изученных букв хранится на телефоне;
- используются собственные MP3, системный TTS отсутствует;
- работает офлайн после первого открытия.

Для GitHub замените index.html, style.css, app.js, sw.js, manifest.webmanifest.
Папки images/ и audio/ из V4 остаются совместимыми, но ZIP V5 уже содержит их.
