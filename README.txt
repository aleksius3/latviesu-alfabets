КАРТИНКИ
Код сначала ищет красивые картинки в папке images:
images/acs.webp
images/abols.webp
...
Если картинки пока нет, автоматически показывается emoji-заглушка.

То есть теперь картинки можно добавлять/заменять без изменения app.js.
Рекомендуемый размер каждой картинки: 600x600 px, WebP или PNG,
прозрачный либо светлый фон, один предмет по центру.

Обновление GitHub:
1. В репозитории замените index.html, style.css, app.js, sw.js, manifest.webmanifest
2. При необходимости добавьте папку images
3. Commit changes
4. Подождите GitHub Pages 1–2 минуты.
